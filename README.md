# 🏢 Escritório Escola

Bem-vindo ao repositório do **Escritório Escola**! Este é o nosso grupo de estudos de faculdade focado em **Desenvolvimento de Software com Java**.

O objetivo deste espaço é unir os alunos para praticar programação, tirar dúvidas e criar projetos juntos para evoluir na carreira.

---

## 📂 Organização das Pastas

*   `fundamentos/`: Códigos de lógica, sintaxe e Orientação a Objetos.
*   `exercicios/`: Exercícios práticos e desafios de código.
---

## 🛠️ O que estamos estudando?

*   Linguagem **Java** (Conceitos básicos e avançados)
*   **Spring Boot** (Criação de APIs e sistemas web)
*   **Git e GitHub** (Trabalho em equipe e versionamento)
